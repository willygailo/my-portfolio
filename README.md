# 🚀 Willy Gailo's Professional Portfolio

A hyper-modern, highly dynamic, and responsive personal portfolio built for a Cybersecurity Specialist & Developer. Designed with a "premium landing page" aesthetic featuring continuous CSS animations, glassmorphism UI, and real-time GitHub integration.

## ✨ Features

- **No Build Step Required:** Built using React via CDN and Tailwind CSS. Just open `index.html` in your browser!
- **Hyper-Dynamic UI:** Everything moves! Features include a starry particle background, infinite tech stack marquee, flowing gradient texts, and floating UI cards.
- **Custom Interactive Cursor:** A custom-built cursor that morphs and interacts with hovered elements.
- **Typewriter Effect:** An engaging typewriter animation highlighting core competencies in the hero section.
- **Live GitHub Graph:** Automatically pulls and displays your real-time GitHub contributions chart.
- **Glassmorphism Design:** Frosty, transparent, beautiful layered backgrounds across all sections.

## 🛠️ Tech Stack

- **HTML5 / CSS3**
- **React 18** (via CDN)
- **Tailwind CSS** (via CDN)
- **Babel** (In-browser transpilation)

## 📂 File Structure

- `index.html` - The main entry point containing the HTML skeleton and CDN links.
- `app.js` - Contains all the React components, logic, and state management.
- `style.css` - Custom continuous CSS animations, scrollbar styling, and Tailwind utilities.

## 🏃 How to Run Locally

You don't need Node.js, npm, or any build tools!

1. Clone or download this repository.
2. Open the folder in your file explorer.
3. Double-click on `index.html` to open it in your default web browser.

## 🚀 How to Deploy

Because this project uses raw HTML/JS/CSS without a bundler, it is extremely easy to deploy for free.

- **GitHub Pages:** Upload the files to a repository and enable GitHub Pages on the `main` branch.
- **Netlify / Vercel:** Simply drag and drop the folder containing these files directly into their web deployment interface.

## 🎨 Customizing

- **To update projects:** Open `app.js` and modify the `portfolioProjects` array.
- **To update the GitHub Graph:** Open `app.js`, find `https://ghchart.rshah.org/3b82f6/willygailo`, and ensure the URL contains your exact GitHub username.
- **To update animations:** Open `style.css` to tweak speeds, colors, or keyframes for the shimmering, floating, and pulsing effects.
